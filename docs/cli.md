# Контракт CLI

`--json` виводить один JSON-об'єкт у стандартний вивід. Його поля:
`schema_version` (ціле число `1`), `command`, `status`, `result`
і `diagnostic`. Машинозчитуваний контракт є в `src/sipl/result-v1.schema.json`.

| Код | Статус | Значення |
|---|---|---|
| 0 | `ok` або `completed` | Команда успішна або обчислення завершилось |
| 2 | `error` | Помилка аргументів, читання, стану або синтаксису |
| 3 | `undefined` | Обчислення потребує значення відсутньої змінної |
| 4 | `limit` | Досягнуто ліміту виконання або представлення результату |

За помилок виклику командного рядка (наприклад, відсутнього аргументу `FILE`)
помилку повідомляє `argparse` і повертає код 2. Для решти помилок у режимі JSON
поле `diagnostic` містить `code`, `message`, `span` або `null`, і масив
`expected` з допустимими лексемами, якщо вони відомі. Позиція містить
`line` і `column`, які починаються з 1. `offset` рахується з 0 у символах
Unicode. Кінець діапазону не включається.

`check` повертає порожній `result`. `parse` повертає `result.ast` з полем
`kind` для типу кожного вузла. `term` повертає `result.term` і текстовий
запис `result.notation`. Для `run`, `trace` і `eval` є
`result.steps` і `result.final_state`. Кінцевий стан дорівнює `null`,
якщо програму не вдалося обчислити. Помилки підготовки або серіалізації дають
порожній `result`.

`trace` додає `result.events`. `BeforeStatement` і `AfterStatement` обрамляють
успішне виконання оператора. `VariableChanged` повідомляє про нове або змінене
значення. `ConditionChecked` містить результат успішної перевірки умови.
Остання подія `ExecutionFinished` має статус і знімок останнього досягнутого
стану. Знімки станів є копіями. Якщо обчислення перерване, останній знімок
показує стан на момент зупинки.

`eval` додає `result.proof`. Кожен запис містить правило з таблиці AF,
фазу, стан і позицію. У записі `AF_WH` з фазою `condition` поле
`iteration` дорівнює кількості вже виконаних ітерацій. Для фази `after_iteration`
стан містить результат цієї ітерації. У записах `AF_S` поле `subject` позначає
базову операцію. Для `AF_AS` і `AF_DNM` це ім'я змінної.
