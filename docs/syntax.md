# Синтаксис базової SIPL

Джерела: практикум, с. 8-10. М. С. Нікітченко, «Теорія програмування», 2010,
§ 1.2, с. 7-11. Виконувана версія граматики лежить у `src/sipl/grammar/sipl.lark`.

| Категорія | Правила курсу | Що реалізовано |
|---|---|---|
| Програма | P1 | `begin S end` |
| Оператор | S1-S6 | Присвоювання, послідовність, `if ... then ... else`, `while ... do`, блок, `skip` |
| Вираз | A1-A6 | Число, змінна, додавання, віднімання, множення, дужки |
| Умова | B1-B5 | Рівність, більше, диз'юнкція, заперечення, дужки |

Щоб отримати один розбір, граматика ділить вирази й умови на рівні пріоритету.
Множення має вищий пріоритет за додавання й віднімання. Порівняння `=` і `>`
мають арифметичні операнди. Заперечення `¬` стосується умови, а диз'юнкція `∨`
має нижчий пріоритет. Бінарні арифметичні операції, диз'юнкція та композиція
лівоасоціативні. Наприклад, `8 - 3 - 2` означає `(8 - 3) - 2`.

Композиція через `;` має найнижчий пріоритет. У `while B do S1; S2` оператор
`S2` виконується після циклу. Якщо обидва оператори належать тілу циклу, потрібен блок
`while B do begin S1; S2 end`. Так само кілька операторів у гілці `if`
об'єднуються в блок.

## Лексика

У БНФ імена й числа наведено схематично. У цій реалізації ім'я починається
з латинської літери й може продовжуватися латинськими літерами або цифрами.
Слова `begin end if then else while do skip` зарезервовано в нижньому регістрі.
Цілі літерали записуються десятковими цифрами. Для від'ємного літерала `-`
стоїть безпосередньо перед цифрою. Наприклад, `X := -2` є присвоюванням
від'ємного числа, а `X := -(Y + 1)` виходить за межі базової БНФ.
Пробіли, табуляція й переноси рядків між лексемами ігноруються.

Коректні записи: `begin skip end`, `begin X := -1 end`,
`begin if ¬(X = 1) ∨ X > 3 then skip else X := 2 end`.

Приклади помилок: `begin end` (немає оператора),
`begin skip; end` (немає другого оператора),
`begin X := 4 / 2 end` (операція відсутня в БНФ),
`begin if X = 0 then skip end` (відсутня обов'язкова гілка `else`).
Умова `Y < 1` записується через порівняння `1 > Y`.
Базовий синтаксис не включає `<`, `<=`, `div`, `mod`, кон'юнкцію,
коментарі чи рекурсивні функції.
